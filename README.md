# sultanops — blog.sultanops.com

المدونة مبنية بـ [Eleventy](https://www.11ty.dev/): تكتب المقالات بملفات Markdown، وEleventy يحوّلها إلى صفحات HTML. الهيدر والفوتر والتصميم مكتوبة مرة وحدة فقط وتنطبق على كل الصفحات.

## التشغيل على جهازك

```bash
npm install
npm start
```

بعدها افتح http://localhost:8080. أي تعديل تحفظه يظهر مباشرة في المتصفح.

## إضافة مقال جديد

1. أنشئ ملف في `src/ar/posts/`، مثلاً `docker-basics.md`. اسم الملف هو رابط المقال: `/posts/docker-basics/`
2. ابدأ الملف بهذه المعلومات ثم اكتب المقال تحتها:

   ```markdown
   ---
   title: أساسيات Docker
   description: جملة أو جملتين تظهر في بطاقة المقال وفي نتائج البحث.
   date: 2026-11-02
   tags: [docker, linux]
   ---

   ## المقدمة

   نص المقال...
   ```

3. للنسخة الإنجليزية: أنشئ ملف **بنفس الاسم** في `src/en/posts/`. زر تبديل اللغة يربط الملفين ببعض تلقائياً. إذا ما فيه نسخة إنجليزية، يودّي الزر للصفحة الرئيسية الإنجليزية.

**لغة الزائر:** أول ما يفتح الزائر أي صفحة لها نسختين، يتحوّل للغة جهازه: الأجهزة العربية تقرأ بالعربي، وأي لغة ثانية تقرأ بالإنجليزي. لما يضغط زر اللغة ينحفظ اختياره ويصير هو المعتمد. محركات البحث ما تتحول. المنطق في `src/_includes/layouts/base.njk`.

المقال يظهر تلقائياً في الصفحة الرئيسية وصفحة المدونة وصفحات التصنيفات و RSS و sitemap. ما تحتاج تعدل أي ملف ثاني.

### الحقول الاختيارية

| الحقل | الفائدة |
| --- | --- |
| `updated: 2026-12-01` | تاريخ آخر تحديث للمقال |
| `image: /assets/images/banner.png` | الصورة اللي تظهر لما ينشارك الرابط في تويتر ولينكدإن (الافتراضية `og-default.png`) |
| `numbered: true` | يرقّم العناوين الرئيسية تلقائياً 01، 02… (مناسب للشروحات) |

### داخل المقال

- **الأكواد:** اكتب نوع اللغة بعد ```` ``` ```` مثل ```` ```bash ```` أو ```` ```yaml ````. التلوين وزر النسخ يضافون تلقائياً.
- **الخطوات المرقّمة:** أي قائمة `1.` `2.` `3.` تظهر كخطوات مرقّمة.
- **فهرس المقال:** يظهر تلقائياً إذا المقال فيه أكثر من 3 عناوين `##`. لا تكتب أرقام في العناوين، الترقيم تلقائي مع `numbered: true`.
- **الصور:** حطها في `src/assets/images/` واكتب `![وصف الصورة](/assets/images/اسم-الصورة.png)`
- **الملاحظات:** أربعة أنواع، لكل نوع لون وأيقونة: `note` (ملاحظة)، `tip` (نصيحة)، `warning` (تنبيه)، `security` (أمان). العنوان اختياري.

  ```markdown
  ::: security نصائح أمانية
  نص الملاحظة هنا.
  :::
  ```

- **التصنيفات (`tags`):** اكتبها بالإنجليزي وبأحرف صغيرة (`aws` وليس `AWS`) عشان تكون نفسها في النسختين. الاسم المعروض والأيقونة والوصف لكل تصنيف في `src/_data/topics.js`. التصنيف الجديد يشتغل بدون ما تضيفه هناك، بس بأيقونة عامة.

## هيكل المشروع

```
src/
  ar/                 الصفحات العربية (الرابط يبدأ من /)
    posts/            المقالات العربية
  en/                 الصفحات الإنجليزية (الرابط يبدأ من /en/)
    posts/            المقالات الإنجليزية
  _data/
    brand.js          الهوية: الألوان، الخطوط، الحركة (مصدر كل قيم التصميم)
    site.js           الدومين، اسم الكاتب، اللغات
    topics.js         أسماء التصنيفات وأيقوناتها ووصفها
    terminal.js       الأوامر اللي تظهر في الطرفية بالصفحة الرئيسية
    i18n.js           نصوص الواجهة (القوائم، الأزرار) بالعربي والإنجليزي
    redirects.json    الروابط القديمة وين تودّي
  _includes/
    layouts/          قوالب الصفحات (الرئيسية، المدونة، المقال...)
    partials/         الهيدر، الفوتر، سطر المقال، الطرفية، الشعار
    icons.js          مجموعة الأيقونات ({% icon "name" %})
  assets/
    css/main.css      كل التصميم (يقرأ القيم من tokens.css المولّد من brand.js)
    js/main.js        المظهر، القائمة، البحث، زر النسخ، الفهرس، حركة الطرفية
    images/           صور المقالات
  static/             ملفات تُنسخ كما هي لجذر الموقع (الأيقونات، CNAME...)
```

## الهوية

كل الألوان والخطوط والحركة في `src/_data/brand.js`. تتحول تلقائياً إلى متغيرات CSS في `/assets/css/tokens.css`، فتغيير اللون الأساسي هناك يغيّر الموقع كامل.

بعد تغيير الألوان، أعد توليد الأيقونات وصورة المشاركة:

```bash
npm run brand-assets
```

الخطوط: IBM Plex Sans Arabic وIBM Plex Mono (رخصة SIL OFL).

## النشر

عند أي push على `main`، يبني GitHub Actions الموقع (`.github/workflows/deploy.yml`) وينشره على GitHub Pages.

يحتاج هذا الإعداد مرة وحدة فقط: في GitHub افتح **Settings → Pages**، ومن **Source** اختر **GitHub Actions**.

إذا غيّرت رابط صفحة، أضف الرابط القديم في `src/_data/redirects.json` عشان الروابط اللي انشاركت قبل تظل شغالة.
