# مدونة تقنية — blog.sultanops.com

المدونة مبنية بـ [Eleventy](https://www.11ty.dev/): تكتب المقالات بملفات Markdown، وEleventy يحوّلها إلى صفحات HTML. الهيدر والفوتر والتصميم مكتوبة مرة وحدة فقط وتنطبق على كل الصفحات.

## التشغيل على جهازك

```bash
npm install
npm start
```

بعدها افتح http://localhost:8080. أي تعديل تحفظه يظهر مباشرة في المتصفح.

## إضافة مقال جديد

1. أنشئ ملف في `src/ar/posts/`، مثلاً `docker-basics.md`. اسم الملف هو رابط المقال: `/posts/docker-basics/`
2. ابدأ الملف بهذه المعلومات ثم اكتب المقال تحتها:

   ```markdown
   ---
   title: أساسيات Docker
   description: جملة أو جملتين تظهر في بطاقة المقال وفي نتائج البحث.
   date: 2026-11-02
   tags: [docker, linux]
   ---

   ## المقدمة

   نص المقال...
   ```

3. للنسخة الإنجليزية: أنشئ ملف **بنفس الاسم** في `src/en/posts/`. زر تبديل اللغة يربط الملفين ببعض تلقائياً. إذا ما فيه نسخة إنجليزية، يودّي الزر للصفحة الرئيسية الإنجليزية.

المقال يظهر تلقائياً في الصفحة الرئيسية وصفحة المدونة وصفحات التصنيفات و RSS و sitemap. ما تحتاج تعدل أي ملف ثاني.

### الحقول الاختيارية

| الحقل | الفائدة |
| --- | --- |
| `updated: 2026-12-01` | تاريخ آخر تحديث للمقال |
| `image: /assets/images/banner.png` | الصورة اللي تظهر لما ينشارك الرابط في تويتر ولينكدإن |

### داخل المقال

- **الأكواد:** اكتب نوع اللغة بعد ```` ``` ```` مثل ```` ```bash ```` أو ```` ```yaml ````. التلوين وزر النسخ يضافون تلقائياً.
- **الخطوات المرقّمة:** أي قائمة `1.` `2.` `3.` تظهر بشكل دوائر مرقّمة.
- **الصور:** حطها في `src/assets/images/` واكتب `![وصف الصورة](/assets/images/اسم-الصورة.png)`
- **الملاحظات:**

  ```markdown
  ::: note 🔐 نصائح أمانية
  نص الملاحظة هنا.
  :::
  ```

- **التصنيفات (`tags`):** اكتبها بالإنجليزي وبأحرف صغيرة (`aws` وليس `AWS`) عشان تكون نفسها في النسختين.

## هيكل المشروع

```
src/
  ar/                 الصفحات العربية (الرابط يبدأ من /)
    posts/            المقالات العربية
  en/                 الصفحات الإنجليزية (الرابط يبدأ من /en/)
    posts/            المقالات الإنجليزية
  _data/
    site.js           الدومين، اسم الكاتب، اللغات
    i18n.js           نصوص الواجهة (القوائم، الأزرار) بالعربي والإنجليزي
    redirects.json    الروابط القديمة وين تودّي
  _includes/
    layouts/          قوالب الصفحات (الرئيسية، المدونة، المقال...)
    partials/         الهيدر، الفوتر، بطاقة المقال
  assets/
    css/main.css      كل التصميم
    js/main.js        الوضع الليلي، القائمة، البحث، زر النسخ
    images/           صور المقالات
  static/             ملفات تُنسخ كما هي لجذر الموقع (الأيقونات، CNAME...)
```

## النشر

عند أي push على `main`، يبني GitHub Actions الموقع (`.github/workflows/deploy.yml`) وينشره على GitHub Pages.

يحتاج هذا الإعداد مرة وحدة فقط: في GitHub افتح **Settings → Pages**، ومن **Source** اختر **GitHub Actions**.

إذا غيّرت رابط صفحة، أضف الرابط القديم في `src/_data/redirects.json` عشان الروابط اللي انشاركت قبل تظل شغالة.
